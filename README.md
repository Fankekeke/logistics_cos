# 基于 SpringBoot + Vue 的跑腿配送系统 (Errand Delivery System)

在线下单 · 即时配送 · 接单中心 · 优惠券 · 物品兑换 · 收益提现 · 订单评价 · 数据统计 · 支付宝沙盒支付

本项目是一套面向校园、社区及同城生活场景的跑腿配送平台，采用前后端分离架构，覆盖管理员、配送员与用户三类角色。系统围绕"用户下单、即时配送、接单派单、优惠券、物品兑换、收益提现、订单评价、数据统计"等核心业务设计，支持用户在线发布跑腿订单（代买、代送、代办等）、支付宝沙盒支付、使用优惠券与物品兑换，配送员通过接单中心抢单配送并管理个人收益与提现，管理员负责订单管理、用户与员工管理、优惠券配置、数据统计与提现审核，实现从下单、支付、接单、配送到评价与结算的全流程数字化管理，适用于校园跑腿、同城配送、社区代购及即时物流服务平台。

## 核心特性

- **多角色权限管理**：区分管理员、配送员与用户三类角色，实现不同权限隔离与功能访问控制。
- **在线下单与支付**：用户可发布代买、代送、代办等跑腿订单，支持支付宝沙盒支付，支付成功后订单进入待接单状态。
- **接单中心**：配送员查看附近待接单订单，支持抢单模式，接单后进入配送流程并实时更新订单状态。
- **优惠券系统**：管理员配置满减券、折扣券、新人券等优惠券，用户领取后在下单时自动抵扣。
- **物品兑换**：用户可使用积分兑换平台物品或优惠券，兑换记录可追溯。
- **配送收益与提现**：配送员查看个人配送收益明细，支持发起提现申请，管理员审核提现记录。
- **订单评价**：用户完成订单后可对配送服务进行评分与评价，评价信息供管理员与配送员查看。
- **数据统计**：以图表形式展示订单量、营收、配送员绩效、用户增长、优惠券使用率、热门物品排行等数据。

## 功能模块概览

## 管理员端

管理员负责平台整体运营、订单管理、用户与配送员管理、优惠券配置、数据统计与提现审核：

### 用户与员工管理

- **用户管理**：管理注册用户信息，包括昵称、手机号、注册时间、账户状态，支持账号启用/禁用。
- **员工管理**：管理配送员（员工）信息，包括姓名、手机号、身份证号、入职时间、工作状态，支持配送员审核与禁用。
- **用户地址管理**：查看用户绑定的收货地址列表，支持异常地址清理。

### 订单与物品管理

- **订单管理**：查看所有订单列表，包括订单状态（待支付/待接单/配送中/已完成/已取消）、下单用户、配送员、金额、时间，支持按状态、时间、用户筛选。
- **物品管理**：管理平台物品/商品信息，包括物品名称、分类、价格、库存、图片，支持物品增删改查，用于物品兑换模块。
- **订单评价信息管理**：查看用户对订单的评价内容、评分与标签，支持评价审核与异常评价处理。

### 优惠券与兑换管理

- **优惠券管理**：配置优惠券模板，包括优惠券类型（满减/折扣）、面额、使用门槛、有效期、发放数量、领取规则，支持优惠券上架/下架。
- **兑换记录**：查看用户物品兑换记录，包括兑换物品、兑换时间、消耗积分、兑换状态。

### 收益与提现管理

- **员工收益**：查看配送员的配送收益明细，包括每单收入、累计收益、提现记录。
- **提现记录审核**：审核配送员发起的提现申请，确认提现金额与到账状态，支持通过/驳回操作。

### 公告与数据统计

- **公告管理**：发布平台公告，包括活动通知、系统维护通知、配送规则变更等，支持置顶与定时发布。
- **数据统计**：以图表形式展示订单总量、日/月订单趋势、营收统计、配送员绩效排行、用户增长曲线、优惠券使用率、热门物品排行等数据。
- **统计图表**：使用 ECharts 可视化展示各类统计数据，支持按时间范围筛选与数据导出。

### 系统设置

- **修改密码**：管理员可修改个人登录密码，密码加密存储，保障账户安全。

## 配送员端

配送员面向平台注册配送员，提供接单、配送、收益管理与个人信息维护功能：

### 账户与个人信息

- **个人信息变更**：维护个人信息，包括姓名、手机号、身份证号、银行卡信息（用于提现）、头像。
- **修改密码**：配送员可修改个人登录密码。

### 订单与接单

- **接单中心**：查看附近待接单订单列表，显示订单类型、距离、配送费、起止地点，支持抢单操作。
- **我的订单**：查看个人已接订单列表，包括订单状态（待取货/配送中/已完成）、订单详情、用户信息、配送地址。
- **我的订单统计**：查看个人订单统计数据，包括今日/本月完成订单数、累计配送里程、平均配送时长。

### 收益与提现

- **我的收益**：查看个人配送收益明细，包括每单收入、累计收益、可提现余额。
- **提现申请**：发起提现申请，选择提现金额与提现方式（支付宝/银行卡），查看提现记录与审核状态。

### 订单评价

- **订单评价**：查看用户对自己配送服务的评价内容、评分与标签，了解服务质量反馈。

## 用户端

用户面向平台注册用户，提供在线下单、支付、订单管理、优惠券与物品兑换功能：

### 账户与注册

- **用户注册**：用户通过手机号注册账号，设置登录密码，支持验证码校验。
- **个人信息**：查看与维护个人基本信息，包括昵称、手机号、头像。
- **修改密码**：用户可修改个人登录密码。

### 下单与支付

- **用户下单**：发布跑腿订单，选择订单类型（代买/代送/代办），填写物品信息、起止地址、备注要求、期望完成时间，系统自动计算配送费。
- **支付宝沙盒支付**：订单确认后通过支付宝沙盒环境完成在线支付，支付成功后订单进入待接单状态。
- **我的优惠券**：查看个人已领取的优惠券列表，包括优惠券面额、使用门槛、有效期、使用状态，下单时自动匹配可用优惠券。

### 订单与评价

- **我的订单**：查看个人订单列表，包括订单状态（待支付/待接单/配送中/已完成/已取消）、订单详情、配送员信息。
- **订单评价**：订单完成后对配送服务进行评分（1-5星）与文字评价，支持上传评价图片。

### 物品兑换

- **物品兑换**：使用积分兑换平台物品或优惠券，选择兑换物品并确认兑换，消耗相应积分。
- **兑换记录**：查看个人物品兑换历史记录，包括兑换物品、兑换时间、消耗积分、兑换状态。

### 地址管理

- **收货地址管理**：添加、编辑、删除收货地址，设置默认地址，支持地址标签（家/公司/学校等）。
